-------------------------------------------------------------------
Build on MSYS2 / MinGW-w64 (MINGW64 shell)
-------------------------------------------------------------------

The full description is in HOWTOBUILD.HTML. In short:

0. Tools:
	pacman -S --needed mingw-w64-x86_64-gcc make patch p7zip zip curl

1. Everything (8.4.20, 8.5.19, 8.6.18, 9.0.4; large and small):
	sh mkdist.sh

   Sources are downloaded to dl/ and unpacked to <root>/tcl, <root>/tk,
   the results end up in dist/:
	tclkit-large-<version>-win-amd64.7z
	tclkit-small-<version>-win-amd64.7z

2. Selected releases, clean rebuild, number of jobs:
	sh mkdist.sh 8.6.18 9.0.4
	sh mkdist.sh -c
	sh mkdist.sh -j 4

3. A single configuration by hand:
	sh fetch.sh 8.6 8.6.18
	sh config.sh 8.6/kit-large cli gui mk thread allenc allmsgs tzdata
	cd 8.6/kit-large && make

   large, 8.x:  cli gui mk thread allenc allmsgs tzdata
   small, 8.x:  cli dyn mk
   large, 9.x:  cli gui thread itcl sqlite allenc allmsgs tzdata
   small, 9.x:  cli dyn

Nothing has to be edited by hand any more (SO, directory names, upx).
